# Behavioral Data Analysis

The analysis notebook processes participant-level CSV files generated by the included PsychoPy experiment.

## Expected input

The notebook reads files from `data/Male/` and `data/Female/`. Each participant file must contain 105 trials, indexed from 0 to 104, and the columns documented in [Data Dictionary](data_dictionary.md).

No participant-level data are distributed in this repository. Run the experiment to generate compatible files locally. See [Data Availability and Generation](../data/README.md).

## Analysis workflow

1. Load participant CSV files and combine the records.
2. Check participant counts, trial counts, missing values, and variable types.
3. Compute block-level reward rate and optimal-choice rate.
4. Compare performance across blocks using repeated-measures non-parametric tests.
5. Examine reaction times across blocks and by choice type.
6. Compare confidence for optimal and non-optimal choices.
7. Compute an operational confidence-discrimination score.
8. Build trial sequences for Q-learning.
9. Fit Softmax, Epsilon-Greedy, and probabilistic UCB variants separately for each participant.
10. Compare models using negative log-likelihood, AIC, and BIC.

## Saved results

The aggregate tables, figures, and saved Notebook outputs in this repository preserve results from the original analysis run. The participant-level source dataset is not included. New participant data generated by the experiment will produce new results, which should not be expected to match the saved numerical values exactly.

## Statistical interpretation

In the saved analysis, reward rate did not show a statistically significant block effect (Friedman χ²(2) = 2.844, p = 0.241), while optimal-choice rate differed across blocks (χ²(2) = 6.680, p = 0.035). Reaction time also differed across blocks (χ²(2) = 68.450, p < 0.001).

Trial-level comparisons of reaction time do not account for the nesting of trials within participants and should be interpreted cautiously. The confidence-difference measure is an operational descriptive score, not a formal metacognitive-efficiency estimate such as meta-d′.
