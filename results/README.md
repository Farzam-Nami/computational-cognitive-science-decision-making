# Saved Analysis Results

This directory contains aggregate tables and figures from the original analysis run.

The participant-level source dataset used for those results is not included in this repository. The saved outputs are retained as research results; they are not generated from synthetic or placeholder data.

Running the included experiment creates new participant records in the format expected by the analysis notebook. Re-running the notebook on newly collected participants will produce new results, which should not be expected to match the saved values exactly.

The notebook also retains its original saved outputs. Participant identifiers shown in saved preview tables have been replaced with neutral sequential labels.
